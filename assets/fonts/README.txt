NotoSansSC-subset.otf: subset of Noto Sans CJK SC (SIL Open Font License 1.1, see LICENSE-NotoSansCJK.txt).
Contains every non-ASCII character used by the game (scripts, scenes, localization/strings.csv) plus common punctuation.
If you add new Chinese text, regenerate it: python3 tools/make_font_subset.py
